# Learn — покадровое описание

| # | 60 с | 45 с | Что на экране |
|---|---|---|---|
| 01 | 0–4 | 0–3 | Открытые вкладки «Видео про AI», «Новый инструмент», «Сохранить на потом» и пустая карточка «Мой проект»; курсор мечется, пунктирная линия маршрута не находит продолжения. Титр «С чего начать?» |
| 02 | 4–9 | 3–5 | Вкладки складываются в три контурные карточки; логотип «Незаменимые», титр «Бесплатный гид по AI-разработке», подпись «Владилен Минин», пиктограммы маршрутов |
| 03 | 9–12 | 5–7 | Карточки «Агент», «AI-инженерия», «Свой проект»; титр «Три задачи. Три маршрута»; первая карточка выходит вперёд |
| 04 | 12–18 | 7–13 | «Собрать первого агента»: бриф (Задача / Правила / Проверка) передаётся в отдельное окно «Твой проект»; кнопка исправлена, курсор проверяет — «Проверено» |
| 05 | 18–24 | 13–19 | «Разобраться в AI-инженерии»: Модель, Инструменты, Знания, Проверка; схема ложится на лист «Мой агент» |
| 06 | 24–30 | 19–25 | «Довести свой проект до результата»: из разрозненных идей выбран «Лендинг с формой»; «План на неделю» с тремя шагами и строкой «Кому покажу результат» |
| 07 | 30–35 | 25–30 | Страница урока: видео → материалы → «Теперь попробуй на своей задаче» («Посмотри разбор / Возьми материалы / Попробуй сам»; в 45 — «Смотри → пробуй → проверяй») |
| 08 | 35–40 | 30–32 | «Вставить шаблон», заметки заполняются, мини-окно «Твой проект»; ручная отметка критерия — «Проверь результат» |
| 09 | 40–45 | 32–34 | «Я сделал» → «Выполнено», 0 / 3 → 1 / 3; возврат к началу гида и карточка «Продолжим с того места, где остановились» (только в 60) |
| 10 | 45–50 | 34–38 | «Результат твоего маршрута»: Бриф агента · Схема агента · План проекта, подсвечен один |
| 11 | 50–54 | 38–41 | «Материалы гида» — «Бесплатно · Без регистрации» |
| 12 | 54–60 | 41–45 | «Выбери маршрут ниже» + «Сделай первый шаг сегодня», три карточки с «Начать маршрут» и стрелкой вниз. Внешний финал: «Открой бесплатный гид», irreplaceable-ai.ru/learn, «Выбери свой маршрут» |
