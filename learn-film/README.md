# Learn — анимационный ролик «Бесплатный гид по AI-разработке»

Ролик по ТЗ от 28.09.2026 («От открытых вкладок к первому результату»), снятый скиллом
[procedural-film](https://github.com/kuhnhomeuk-cell/procedural-film): каждый кадр рисуется кодом на canvas,
музыка и эффекты синтезируются в Web Audio. Видео, субтитры, дорожки и обложка — детерминированный рендер из
исходников этой папки.

## Что сдаётся (`exports/`)

| Файл | Что это |
|---|---|
| `learn-60-page.mp4`, `learn-45-page.mp4` | основные версии для страницы Learn (финал «Выбери маршрут ниже») |
| `learn-60-external.mp4`, `learn-45-external.mp4` | финал для внешнего размещения (irreplaceable-ai.ru/learn) |
| `*-subtitled.mp4` | те же версии со вшитыми субтитрами |
| `learn-{60,45}-{page,external}.{srt,vtt}` | субтитры (текст диктора из ТЗ) |
| `audio/learn-{60,45}-{mix,music,sfx}.wav` | 48 кГц / 24 бит: микс, музыка, эффекты отдельно |
| `learn-cover.jpg`, `learn-cover.webp` | обложка 1920×1080 «Что ты сделаешь с AI?» |
| `learn-shots.md` | покадровое описание для подписи/публикации |

Видео: 1920×1080, 25 к/с CFR, H.264 High, BT.709, AAC 48 кГц, fast start; звук нормализован до −16 LUFS
integrated, true peak ≤ −1 dBTP. `dist/learn-film.html` — интерактивный плеер (пробел — play, стрелки — покадрово).

## Чего нет и почему

- **Голос диктора.** Код не может записать живой голос Владилена. Ролик собран под текст диктора из ТЗ: реплики
  стоят в своих сценах (см. субтитры — это и есть разметка озвучки), музыка оставляет место под речь.
  Запишите голос по SRT и положите поверх `audio/*-music.wav` + `*-sfx.wav` (или поверх MP4, приглушив
  музыку на ~6 дБ под речью).
- **ProRes-мастер.** Генерируется командой `node tools/deliver.cjs --prores` (≈1 ГБ на файл — в git не кладётся).
- **Пиктограммы маршрутов.** Оригинальный `RouteGlyph` из `app/learn/GuideChrome.jsx` (ветка
  `codex/ai-learning-routes`) не опубликован на GitHub, поэтому робот / схема / ступени перерисованы линиями в том же
  стиле (`src/props.js`, `ui.glyph`). Логотип, фото, шрифты Onest и JetBrains Mono — настоящие, из `club_landing`.
- **Тексты урока** («Первый агент в своём проекте», пункты материалов и критериев) — правдоподобные заглушки по
  смыслу ТЗ; реальные заголовки из `content/learn/catalog.json` подставляются в `src/props.js` (константы
  `LESSON`, `MATERIALS`, `CRITERIA`, `TEMPLATE`).

## Как пересобрать

```bash
npm install --prefix tools                     # Playwright (использует /opt/pw-browsers/chromium, если есть)
node tools/cuts.cjs --cut 60 --subs            # выбрать вариант: --cut 60|45, --ending page|external, --subs
node tools/check.cjs                           # проверки: медиа, детерминизм, таймлайн, отрисовка, стоимость кадра
node tools/snap.cjs --samples 24 --sheet --scale 0.25   # весь фильм на одном листе
node tools/deliver.cjs                         # весь комплект в exports/
```

Нужны Node 20+ и ffmpeg с libx264/libwebp в PATH (или `FFMPEG=/path/to/ffmpeg`).

## Устройство

- `docs/storyboard.md` — раскадровка обеих версий с таймкодами и общей геометрией стыков.
- `docs/art-bible.md` — визуальный язык Learn, правила движения и «точность обещаний».
- `src/props.js` — UI-кит `FILM.ui`: карточки, окна, кнопки, курсор, линия маршрута, бриф, схема, план, страница урока, субтитры.
- `src/scenes/01…12-*.js` — 12 сцен; каждая содержит расписание для 60- и 45-секундной версии.
- `src/music.js` — партитура (120 BPM, полутемп, фа мажор) и звуки на каждое действие; привязка к `cues` таймлайна.
- `tools/cuts.cjs` — все таймкоды, субтитры и звуковые метки обеих версий; `tools/brand.cjs` — встраивание логотипа и шрифтов.
