# «Кто контролирует работу AI-агента?» — моушн-ролик для сторис

60 секунд, 1080×1920, 24 fps. Цель — привести разработчика на форму бесплатного урока «От AI-кодинга к AI Engineering».
Ролик сделан скиллом [procedural-film](https://github.com/kuhnhomeuk-cell/procedural-film): каждый пиксель нарисован на canvas в JavaScript, каждый звук синтезирован в Web Audio. В проекте нет ни одной картинки, видео или аудиофайла. Стиль продолжает прогрев от 22 сентября: чёрный фон, белая типографика, оранжевые сигналы, технический интерфейс.

## Важные координаты (кадр 1080×1920)

- **Зона стикера ссылки:** x 270–810, y 1190–1350, центр ≈ (540, 1270). Её отмечают оранжевые уголки и указывает стрелка; внутри зоны ничего не нарисовано.
- **Слот под реальный кадр урока:** сцена 08, с 00:41.0 до 00:45.0, прямоугольник x 144, y 640, 792×684. Камера там неподвижна: если появится настоящий фрагмент урока, его можно положить поверх интерфейса. Без него ролик честно показывает схему проекта, без портрета и фальшивого плеера.
- **Безопасные зоны Instagram:** весь обязательный текст — внутри x 72–1008, y 250–1540.

## Звук

- Музыка и звуки написаны как подложка под голос. Интегральная громкость около −22 LUFS, true peak около −5 dBFS. В диапазоне голоса (≈ 300 Гц – 2,5 кГц) под каждой фразой оставлено место.
- Драматургия: подъём до 06.5 обрывается на «пока». На 12.5 стоп-кадр и приглушённый сигнал. На 17.5 пауза на вопросе, с 18.5 механический пульс. На 37.5 разрешение аккорда на зелёном тесте. С 39 музыка раскрывается, на 55.0 финальная каденция, дальше тишина под нажатие стикера.
- После наложения голоса итоговый микс стоит вывести на −14…−16 LUFS.

## Пересборка

Нужны Node 20+, ffmpeg и Chromium. В облачной сессии использовался предустановленный `/opt/pw-browsers/chromium-1194`, свой путь можно задать через `CHROMIUM_PATH`.

```bash
npm install --prefix tools
node tools/check.cjs          # шесть проверок: медиа, детерминизм, источники, таймлайн, отрисовка, стоимость кадра
node tools/deliver.cjs        # все файлы из exports/ + HTML-плеер
node tools/snap.cjs --samples 30 --sheet --scale 0.25   # весь фильм на одном листе
```

Текст субтитров и тайминги лежат в `src/timeline.js` (`captions`). Правка текста — изменить строку и запустить `node tools/deliver.cjs`.
